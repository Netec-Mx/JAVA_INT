# JAVA INT - Laboratorios

Esta página funciona como índice principal del curso y reúne todas las prácticas del proyecto de banca electrónica desarrolladas a lo largo de los capítulos.

## Índice de prácticas

| # | Práctica | Descripción | Duración aproximada |

## Resumen general

El proyecto está centrado en evolucionar una aplicación bancaria a lo largo del curso, incorporando progresivamente conceptos clave de Java como:

- Programación orientada a objetos.
- Colecciones y Streams.
- Entrada y salida de datos.
- Fechas y validaciones.
- Concurrencia.
- Persistencia con bases de datos.
- Internacionalización.
- Módulos de Java.

Puedes comenzar desde la práctica 1 y seguir el orden de desarrollo para construir el sistema de forma progresiva.
